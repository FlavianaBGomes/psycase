# PsyCase Ψ

O PsyCase é uma plataforma web em desenvolvimento para apoio à prática clínica em Psicologia. O projeto foi criado para ajudar profissionais a organizar e acompanhar casos ao longo do processo terapêutico, mantendo o prontuário como fonte principal das informações.

A plataforma propõe recursos como prontuário por sessões, Ecos, Fenômenos, Contextos, linha do tempo, sínteses e uma representação visual do caso em formato de constelação, permitindo acompanhar recorrências, acontecimentos e mudanças ao longo do tempo.

A inteligência artificial é utilizada como ferramenta de apoio para localizar, organizar e sintetizar informações, sem realizar diagnósticos ou substituir a interpretação clínica do psicólogo.

Tecnologias

TypeScript • React • Vite • TanStack • Bun • Drizzle ORM • Supabase
